# 🏭 Web-приложение "ФАБРИКА" (Учет складской продукции)

Репозиторий содержит проект по веб-разработке, реализующий информационную систему для учета готовой продукции на складе фабрики по пошиву одежды. Система позволяет отслеживать поступление товаров разных моделей в течение года и управлять процессом обработки заказов.

## 📝 Описание
Проект представляет собой классическое серверное веб-приложение для автоматизации складского учета. Оно разграничивает доступ между обычными пользователями (клиентами/заказчиками) и сотрудниками фабрики, предоставляя каждому типу пользователей свой интерфейс и набор действий для работы с каталогом продукции и заказами.

## ⚡ Функциональные возможности
- **Аутентификация и авторизация**: регистрация новых пользователей и безопасный вход в систему.
- **Ролевая модель**: 
  - *Личный кабинет пользователя*: просмотр своих заказов, создание новых заявок.
  - *Кабинет сотрудника*: управление складом, просмотр всех заказов, изменение их статусов.
- **Каталог продукции**: просмотр доступных моделей одежды (с отдельным представлением для неавторизованных посетителей).
- **Управление заказами**: создание заказа пользователем, взятие заказа в работу сотрудником, обновление статусов выполнения.
- **Адаптивный интерфейс**: стилизация страниц с использованием CSS для удобного взаимодействия.

## 💻 Технологический стек
- **Backend**: PHP (серверная логика, обработка форм, работа с сессиями)
- **Frontend**: HTML5, CSS3
- **База данных**: MySQL / MariaDB (реляционная модель данных)
- **Архитектура**: Классическая серверная генерация страниц (Server-Side Rendering)
